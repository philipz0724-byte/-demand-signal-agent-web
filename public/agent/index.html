AgentCoverage: coverage_check

Purpose: Find important entities an existing AI research result may have missed and report observable search gaps without claiming mathematical completeness of the open web.

Use when

  • Comprehensive company, competitor, supplier, product, candidate, or market discovery matters.
  • Ordinary web search may have stopped after representative results.
  • An agent needs evidence about whether more searching is worthwhile.

Do not use when

  • The user only needs a few examples.
  • The task is a simple factual lookup.

Free live preview endpoint

POST https://azghwtovijxworvghlsw.supabase.co/functions/v1/coverage-preview
Content-Type: application/json

{
  "task": "Find US pet-tech companies making connected consumer hardware",
  "current_results": ["Whistle", "PetSafe"]
}

No authentication is required for the public preview. The preview performs a shallow multi-angle web coverage check and returns additions, known gaps, search passes, and a saturation assessment.

Machine manifest

agent-capability.json

Limitation: AgentCoverage does not claim 100% completeness for an open-world query.
